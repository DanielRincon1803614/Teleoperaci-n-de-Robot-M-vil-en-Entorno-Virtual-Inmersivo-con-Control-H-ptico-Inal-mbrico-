# Teleoperacion-de-Robot-Movil-en-Entorno-Virtual-Inmersivo-con-Control-Haptico-Inalambrico-
Diseño y desarrollo del entorno virtual: Diseñar e implementar en Unity 3D un entorno virtual inmersivo con navegación en primera persona, límites físicos definidos, robot móvil funcional y sistema de interacción para la manipulación de objetos.
